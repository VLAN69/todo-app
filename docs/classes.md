# Классы: Список дел (To-Do List)

## Классы

| Класс | Атрибуты | Методы | Назначение |
|---|---|---|---|
| Task | title: str, deadline: str, done: bool | mark_done(), __str__() | Одно дело: название, срок и статус. |
| TaskManager | tasks: list[Task] | add_task(), remove_task(), get_all(), find_by_title() | Управление списком дел. |
| TaskStorage | filename: str | load(), save() | Чтение и запись списка в файл. |
| ConsoleUI | manager: TaskManager | run(), print_menu(), print_tasks() | Меню, ввод и вывод в консоли. |

## Связи
- ConsoleUI → TaskManager: ассоциация. Интерфейс хранит ссылку на менеджера (поле manager) и обращается к нему.
- TaskManager ◇— Task: агрегация, один менеджер содержит много дел (1 к 0..*). Дело существует как самостоятельный объект.
- TaskManager ┄> TaskStorage: зависимость (пунктир). Менеджер использует хранилище при загрузке и сохранении, но не владеет им.
- TaskStorage не связана с ConsoleUI: зависимость идёт только вниз (интерфейс → логика → хранение). Хранилище ничего не знает про интерфейс.

## Соответствие коду
Класс Task в logic.py совпадает с диаграммой: поля title, deadline, done и методы mark_done(), __str__(). Остальные классы будут реализованы в следующих лабораторных работах. Если код меняется, диаграмму нужно обновить (и наоборот).
