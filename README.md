# Список дел (To-Do List) учебный проект

Консольное приложение на Python для учёта дел. Учебный проект по дисциплине «Технология разработки программного обеспечения».

## Запуск

```
python main.py
```

## Структура проекта

- main.py - точка входа
- ui.py - меню, ввод и вывод
- logic.py - бизнес-логика (дела, статусы)
- storage.py - хранение (файл tasks.txt)
- docs/ARCHITECTURE.md - описание архитектуры
